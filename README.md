# 🧠 Dynamic Programming & Data Structures — FIAP

Repositório desenvolvido durante as aulas de **Dynamic Programming** da **FIAP**, utilizando Python para estudar e implementar estruturas de dados, com foco em **Heaps**, filas de prioridade e algoritmos de ordenação.

## 📚 Sobre o projeto

Este projeto reúne exercícios e implementações desenvolvidos durante as aulas, explorando o funcionamento de estruturas **Min Heap** e **Max Heap**.

Além da implementação manual dessas estruturas, o projeto também utiliza o módulo nativo `heapq` do Python para comparar diferentes formas de trabalhar com heaps e filas de prioridade.

O objetivo principal é compreender, na prática, como essas estruturas funcionam internamente e como podem ser aplicadas na resolução de problemas de programação.

## 📂 Estrutura do projeto

```text
FIAP--DynamicProgramming/
│
├── heap.py
├── main.py
├── ex01.py
├── ex02.py
└── ex03.py
```

### `heap.py`

Contém as implementações das estruturas:

- `MaxHeap`
- `MinHeap`

As classes implementam operações fundamentais como inserção, remoção, consulta ao elemento da raiz e reorganização dos elementos para manter as propriedades do Heap.

### `main.py`

Arquivo utilizado para testar as estruturas implementadas em `heap.py`, executando operações de inserção, remoção e visualização dos elementos.

### `ex01.py`

Exercício relacionado ao **Heap Sort**, explorando tanto a implementação própria de Heap quanto o módulo `heapq` do Python.

### `ex02.py`

Exercício utilizando `heapq` e manipulação de prioridades para trabalhar com elementos de maior valor utilizando a estrutura de Min Heap disponibilizada pelo Python.

### `ex03.py`

Exercício envolvendo organização e comparação de dados utilizando tuplas.

## 🧩 Conceitos praticados

Durante o desenvolvimento deste projeto foram trabalhados conceitos importantes de algoritmos e estruturas de dados, como:

**Heap**

Estrutura de dados baseada em árvore binária que mantém uma relação específica entre seus elementos.

**Min Heap**

O menor elemento permanece na raiz da estrutura.

**Max Heap**

O maior elemento permanece na raiz da estrutura.

**Heap Sort**

Algoritmo de ordenação baseado na estrutura Heap.

**Priority Queue**

Estrutura em que os elementos são processados de acordo com sua prioridade.
